# Saferry Presentation Checklist

## Demonstration flow
1. Launch Saferry.
2. Show Home and explain the four main features.
3. Open Ferry Schedules and switch the route/date.
4. Open Safety Tips and switch Sea Travel / Beach Safety.
5. Open Emergency Contacts and demonstrate the call action.
6. Open About & Info and show offline-first / install information.
7. Open the hamburger menu and demonstrate navigation.
8. Turn off internet and refresh to demonstrate offline access.
9. Explain that schedule/emergency data must be periodically re-verified.

## Project message
Saferry consolidates key travel information into one lightweight offline-first app so users can access ferry references, practical safety guidance, and emergency contacts even when connectivity is unreliable.

## v14 data/update demonstration
- Explain that the PWA uses curated JSON rather than runtime scraping.
- Show the primary operator/government source list.
- Explain the online-refresh → local-cache → offline-fallback flow.
- For the final demo, connect a GitHub data repository and change one test entry after source verification.
